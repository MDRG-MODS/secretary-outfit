## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/secretary-outfit/releases) page and download `Secretary outfit.zip`.
2. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract `Secretary outfit.zip` into your `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/Secretary outfit/mod.json
   ```
4. Launch the game and visit the Clothier to obtain and equip the outfit.
