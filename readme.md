An elegant office secretary clothing modification for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)**.

---

## 🎮 Features

- **Full Office Attire Set:** Lace Bra & Undergarments, Pencil Skirt, Collared Blouse, and Sheer Stockings.
- **Multilingual Support:** Localized in English, French (`fr`), and Simplified Chinese (`zh-Hans`).
- Compatible with MDRG version **v0.97.12** (Target: `0.97.11`).

---

## ⚙️ Mod Type

This is an **Internal Mod**, designed to be imported, enabled, and managed directly using MDRG's built-in in-game mod manager (available on PC, Mac, and Android). It does not require external modding tools or loaders such as LemonLoader.

Ready-to-use mod packages are available under the [**Releases**](https://github.com/MDRG-MODS/secretary-outfit/releases) tab.
